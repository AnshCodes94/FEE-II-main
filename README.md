## 📂 Repository Structure

```text
fee/
├── 📁 .vercel/             # Vercel deployment configurations
├── 📁 Frontend/            # Additional front-end static modules & UI assets
├── 📁 HTML/                # Semantic HTML concepts, structure exercises & demos
├── 📁 JavaScript/          # Core JS practice, DOM scripts, ES6 features
├── 📁 Notes/               # Comprehensive lecture notes & revision materials
├── 📁 public/              # Static assets served directly by Vite
├── 📁 src/                 # Main React source code (Components, Hooks, App logic)
├── 📄 eslint.config.js     # ESLint configuration for static analysis
├── 📄 index.html           # Main HTML entry point for the React app
├── 📄 package.json         # Project metadata, dependencies, and npm scripts
└── 📄 vite.config.js       # Vite bundler setup and plugin configurations
