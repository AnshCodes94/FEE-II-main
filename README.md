## 🛠 Tech Stack Implementation

| Technology / Tool | Implementation Details & Badges |
| :--- | :--- |
| **React 18 & Vite** | SPA built using functional components, dynamic hooks (`useState`, `useEffect`), JSX syntax, and Vite for fast Hot Module Replacement (HMR).<br>![React](https://img.shields.io/badge/Framework-React_18-blue?style=flat-square) ![Vite](https://img.shields.io/badge/Bundler-Vite-purple?style=flat-square) |

| **ESLint Tooling** | Static analysis configured via `eslint.config.js` to enforce React Hooks best practices and clean code standards.<br>![ESLint](https://img.shields.io/badge/Linter-ESLint_9.x-4B32C3?style=flat-square) |
| **Deployment** | Configured for continuous deployment (CD) via Vercel.<br>![Vercel](https://img.shields.io/badge/Hosting-Vercel-black?style=flat-square) |
